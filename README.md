📜 Shams Management System
A Student Management System for Shams Commercial Institute, built using Django to manage student admissions, attendance, fees, course slots, and more.
________________________________________
🚀 Features

✅ Single Admin User
✅ Student Admission & Profiles
✅ Course & Slot Management
✅ Attendance Tracking
✅ Fee Management (Monthly & Package-based)
✅ Income & Expense Tracking
✅ Instructor Assignment to Slots
✅ Reports, Fee Slips & Student ID Cards
✅ Institute Branding in Reports

📥 Installation
1.	Clone the Repository
sh
CopyEdit
git clone https://github.com/affanahmed0/Shams-Management-System.git
cd Shams-Management-System
2.	Set Up Virtual Environment
sh
CopyEdit
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
3.	Install Dependencies
sh
CopyEdit
pip install -r requirements.txt
4.	Apply Migrations
sh
CopyEdit
python manage.py migrate
5.	Create Superuser (For admin access)
sh
CopyEdit
python manage.py createsuperuser
6.	Run the Server
sh
CopyEdit
python manage.py runserver
7.	Access the System
Open http://127.0.0.1:8000 in your browser.
________________________________________
🎮 Usage
•	Admin Panel: Manage students, courses, fees, and reports.
•	Student Management: Add/edit student details and track their progress.
•	Course Slots: Assign students to specific time slots.
•	Fees: Manage payments, generate fee slips, and track outstanding dues.
